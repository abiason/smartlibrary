# SmartLibrary v1.0.0

Primeira release oficial do SmartLibrary.

## Resumo

Esta release consolida o SmartLibrary como sistema academico de biblioteca em C17, com PostgreSQL, MongoDB, interface console V5, testes automatizados, documentacao final, roteiro, video de apresentacao e diagramas.

## Principais Recursos

- Aplicacao console em C17.
- PostgreSQL como banco transacional.
- MongoDB para eventos, logs e auditoria.
- Login obrigatorio, perfis e permissoes.
- Senhas com hash BCrypt via `pgcrypto`.
- Primeiro acesso com criacao/recuperacao de administrador.
- Troca de senha pelo usuario autenticado.
- Cadastros completos: criar, listar, buscar, alterar e excluir/desativar.
- Emprestimos, devolucoes e renovacoes transacionais.
- Reservas com criacao, cancelamento, atendimento, expiracao e listagem.
- Self Checkout com identificacao por CPF e operacoes por codigo/RFID.
- Relatorios operacionais.
- Auditoria antes/depois com operador autenticado.
- Setup local automatizado.
- Interface console V5 com menus, formularios, mensagens e tabelas padronizadas.
- Testes integrados com bancos isolados.

## Validacao

Release validada com:

```powershell
mingw32-make all
$env:POSTGRES_PASSWORD='sua_senha'
mingw32-make test
git diff --check
```

Resultado esperado dos testes:

```text
[TEST] OK: build, login/perfis, regras Fase 14, cadastros V2, fluxo, relatorios, PostgreSQL e MongoDB validados.
```
